매물 지도

지도에서 매물명과 위치를 바로 확인할 수 있습니다.

전체 매물

검색 결과와 지도 위치가 함께 연결됩니다.

매물 등록

주소를 넣으면 카카오맵에서 위치를 자동으로 찾습니다.

엑셀 관리

매물 목록을 내려받거나 엑셀 파일을 가져옵니다.
엑셀 업로드 시 `property_name` 또는 `매물명`, `address` 또는 `주소`가 있으면 주소를 기준으로 지도 좌표를 자동으로 찾습니다.

직원 관리

현재 로그인 계정과 직원 권한 구조를 관리합니다.
직원 계정 추가

직원 계정은 Supabase Authentication에서 이메일/비밀번호로 만든 뒤, `profiles` 테이블에서 role을 `staff`로 지정하는 방식으로 운영합니다.

사용 안내

일반 방문자: 지도, 검색, 매물 상세, 사진 보기만 가능합니다.

직원/관리자: 매물 등록, 수정, 삭제, 사진 업로드, 엑셀 업로드/다운로드가 가능합니다.

지도: 매물명은 핀 위에 항상 표시됩니다. 목록을 클릭하면 지도도 해당 매물 위치로 이동합니다.
